# 卖家中心设计器

# 安装命令
    npm install --legacy-peer-deps
    
# 启动命令
    npm run dev

# 编译命令
    npm run build
    
    编译后的文件复制到
    toucan-shopping\toucan-shopping-front-templates\toucan-shopping-seller-web-templates\src\main\resources\static\lib\designer\pc\index
    修改index.html,资源引入
    1.将/css替换成css
    2.将/js替换成js
